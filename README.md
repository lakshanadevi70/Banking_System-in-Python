# Banking_System-in-Python

##🏦 Banking System in Python
A simple console‑based banking system in Python that lets users log in, check balance, deposit, withdraw, and logs transactions in an Excel file.

## 📌 Overview
This program simulates basic banking operations using user credentials stored in an Excel file (Book.xlsx). After logging in, users can check balance, make deposits and withdrawals, and all actions are recorded with timestamps.

## 🛠️ Tools & Technologies
- Python
- openpyxl for Excel file handling
- datetime and getpass for timestamps and secure login

## 📋 Features
✅ User login with ID and password
✅ Check current balance
✅ Deposit money
✅ Withdraw money
✅ Transactions logged in Excel

## 🚀 How to Run
- Install dependencies:
     pip install openpyxl
- Make sure you have:
- Book.xlsx with:
   Sheet1 → user IDs & passwords
   Sheet2 → transaction logs
- Run the script:
   python main.py

## 📝 Learning Outcome
This project helped me practice Python basics, working with external files (Excel), handling user authentication, and logging operations in a real‑world console application.

## 📌 Notes
You can extend this project later by saving each user’s balance, adding user creation, or improving security.
